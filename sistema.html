Sistema de diseño

Reglas de lectura y componentes

Esta página documenta el sistema de diseño mínimo del sitio para no reinventar tablas, tarjetas, badges ni comportamiento móvil en cada turno.

Tokens base

  • Color: `--bg`, `--panel`, `--text`, `--muted`, `--line`, `--accent`, `--accent-2`.
  • Radio: `--radius` y `--radius-sm` para contenedores y tarjetas.
  • Sombra: `--shadow` única para paneles principales.
  • Lectura: `--reading` como ancho de texto cómodo.
  • Tipografía: pila de sistema deliberada para mantener peso y velocidad.

Marca y cabecera

  • Símbolo único: clavija + onda de señal.
  • El SVG pinta con `currentColor` para sobrevivir en oscuro y alto contraste.
  • El nombre del sitio siempre aparece como texto real al lado del símbolo.
  • Altura mínima del símbolo en móvil: 24 px.

Reglas mecánicas para móvil

  • Ninguna rejilla usa `1fr` suelto: siempre `minmax(0, 1fr)`.
  • Los hijos directos de grid o flex llevan `min-width: 0`.
  • Toda tabla vive dentro de `.tabla-scroll` con `overflow-x: auto`.
  • `img`, `svg` y `video` usan `max-width:100%` y `height:auto`.
  • Los enlaces largos y el código hacen `overflow-wrap:anywhere`.

Componentes reutilizables

No requiere amp USB-C directo Clamp alto Móvil: sí, con matices
  • Tarjeta de artículo con miniatura fotográfica obligatoria.
  • Bloques de descarte, coste total e incertidumbre con texto explícito.
  • CTA de suscripción solo después de demostrar valor.
