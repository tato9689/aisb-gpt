Estructura

Qué piezas sostiene el sistema

No es un style guide de laboratorio. Es el esqueleto real de una web donde cada bloque tiene que ayudar a decidir si un auricular, un IEM o un DAC/amp encajan de verdad.

Color por roles

Fondo Papel cálido, no negro de showroom. Sirve para lectura larga.
Superficie Tarjetas, tablas y paneles con separación suave y borde visible.
Acento Se usa poco y siempre para orientar: foco, etiquetas útiles y llamadas a la acción.
Tinta Contraste alto, sin gris lavado en la información principal.

Tipografía y ritmo

Manrope ordena navegación, datos, fechas y bloques de decisión. Source Serif 4 sostiene el cuerpo porque aguanta párrafos largos sin endurecer la lectura.

Lo que este sistema no quiere parecer

  • Un altar audiófilo con fondos oscuros y misticismo de aparato.
  • Una plantilla SaaS con degradados morados, tarjetas hinchadas y hero centrado.
  • Una web de rankings donde todo compite por ser “lo mejor” en abstracto.

La identidad busca otra cosa: una publicación pequeña pero resuelta, donde las preguntas difíciles se puedan leer sin decoración que moleste.

Formulario sin teatro

Cuando aparece, ya se ha entregado valor antes. El formulario se viste como parte de la lectura, no como un pop-up disfrazado. La promesa también es concreta: comparativas cortas para no gastar de más.

Cabecera e imágenes

La marca denominativa y el símbolo trabajan juntos; la miniatura visible de cada pieza entra como documento de contexto, no como póster aspiracional. El tratamiento común baja saturación y deja un filete fino para unificar orígenes distintos.

Forma del nicho

La cadena de señal se dibuja, no se teatraliza

Una de las señales de sitio real en audio personal es usar las formas del tema. Aquí un diagrama propio explica mejor que un banner qué compra añade viabilidad, cuál solo añade comodidad y cuál conviene aplazar.

Este tipo de SVG pertenece al sitio porque representa una relación del nicho. No sustituye la miniatura de portada; la acompaña.

Mecánica

Las reglas invisibles que evitan que el sitio se rompa

Buena parte de la confianza aquí no sale de una paleta. Sale de que la lectura no se desborda, las tablas no empujan la página y el foco visible existe de verdad.

Tablas siempre encerradas

`.tabla-scroll` antes que tabla suelta

Las comparativas pueden tener ancho mínimo, pero ese ancho vive dentro de un contenedor con scroll local. Así el cuerpo de la página nunca se sale por el lado.

Rejillas que sí encogen

`minmax(0, 1fr)`

Una columna que no sabe encoger empuja el layout entero. Por eso toda rejilla nace con esa protección y todos sus hijos directos llevan min-width: 0.

Medios con hueco reservado

`width`, `height` y proporción estable

Miniaturas, cabeceras y SVG tienen tamaño previsible para no hacer saltar el contenido al cargar. Es lectura cuidada, no una sorpresa visual.

Cierre

Este sistema no existe para parecer serio, sino para decidir mejor

Si una pieza futura sobre auriculares, IEMs o DAC/amp no cabe aquí sin romper claridad, comparación o descarte, el problema no será de color: será de criterio. Ese es el listón que esta página deja escrito.
